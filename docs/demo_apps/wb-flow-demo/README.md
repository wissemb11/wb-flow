# wb-flow-demo

This is the 60s Stripe fixture for the wb-flow demo.
It provides a minimal Node.js / Express backend to demonstrate agentic capabilities.
It deliberately contains no frontend frameworks or bloat, avoiding complex setup.
This fixture is perfect for recording the hero GIF and doing basic checkout tests.

## Structure
- `server.js`: Main Express entrypoint
- `routes/stripe.js`: Stub routes for Stripe integration
- `services/billing.js`: Stub business logic
