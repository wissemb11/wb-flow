# /wbStandup — ELI5

Yesterday you left things half-done. You don't remember exactly what.

`/wbStandup` reads yesterday's reports (and the last few days') and tells you: here's what's still in flight, here's what's still broken, here's what I think you should do first.

Run it **first thing every morning.** It's the cheapest way to avoid the "what was I doing?" drift. 30 seconds, and you know where you are.

It doesn't write code. It just reads state and reports back.
