# /wbHelp — ELI5

`/wbHelp` is the menu. You forgot what `/wbX` does or which commands exist? Type `/wbHelp` and you get the whole menu in a table. Type `/wbHelp wbAudit` and you get just that one entry's manual.

It doesn't *do* anything — it only prints. No reports, no file writes, no waiting around.

You'll use it three times a day in a heavy session, and zero times in a light one. That's fine — it's a lookup tool, not a workflow step.
