# /wbIdea — ELI5

You have an idea for something that might be worth building, but you're not ready to commit to a plan. You register it with `/wbIdea` so it doesn't get lost.

The idea gets a score (1–10) — how badly it should become a real task. Later, you or another AI validates it: promote it to a plan, defer it, or kill it.

Think of it as a parking lot for "what if?" thoughts. Ideas sit between `/wbVision` (dreaming) and `/wbPlan` (committing):

```
wbVision ──► wbIdea ──► wbPlan ──► wbWork ──► wbValid
 (dream) (capture) (commit) (execute) (verify)
```

Ideas that score 8+ and get validated as `🎯 Promoted` automatically become plan tasks next time you run `/wbPlan`.
