# /wbContext — ELI5

You left notes on your desk yesterday about what you were doing. This morning, before touching anything, you re-read the notes.

`/wbContext` is the AI re-reading the notes for a specific package (or for the whole monorepo).

Without it, the AI walks in, looks at your code, and guesses what's going on. With it, the AI reads what *you already figured out* and picks up where you left off.

Run it at the start of every session. Run it again if you changed a lot of code.
