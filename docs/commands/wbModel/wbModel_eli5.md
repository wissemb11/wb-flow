# `/wbModel` — Simple Explanation (ELI5)

Think of `/wbModel` like a smart assistant in a team of software developers.

Imagine you have a team with a **Planner** (who designs the strategy), a **Worker** (who writes the code), a **Validator** (who reviews the work), and a **Helper** (who runs test scripts).

When you give a command like `/wbModel`, `/wbModel` makes sure the right team member does the job using the right AI model.

### Fail-Proof Fallbacks
If your primary AI model runs out of credits or has an error, `/wbModel` automatically switches to a backup AI model using `.wb/bin/wbRun` so your project never gets stuck!
