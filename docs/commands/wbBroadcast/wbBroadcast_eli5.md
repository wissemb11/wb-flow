# /wbBroadcast — ELI5

You shipped something users will actually notice. Now you need to tell the world.

`/wbBroadcast` writes the announcement: a LinkedIn post, a Twitter post, GitHub release notes, and a blog paragraph. All in different voices because each platform has different audiences.

**Important:** it writes. It does NOT post. You review, edit, and post yourself. AI drafts are starting points, not finished copy.

Run it only when the release is user-visible. Internal refactors don't get broadcasts — announcing them dilutes attention for real news.
