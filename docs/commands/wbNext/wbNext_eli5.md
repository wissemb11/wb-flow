# /wbNext — ELI5

You don't know what to run next. The AI does.

`/wbNext` reads recent `reports/`, your git status, and your `dev.md`. It picks the single most useful next command for you to run — and tells you the prompt to type.

It's `/wbStandup`'s smaller cousin: standup tells you what's in flight everywhere; next tells you the one thing you should do *now*.
