# /wbPlan — ELI5

Before you build something complicated, you write a checklist.

`/wbPlan` is the AI writing that checklist *for* you. It takes your goal ("add a button that exports to CSV"), breaks it into small concrete tasks, and saves the list as a file you can tick off.

The trick: the list is saved, not thrown away. If you stop working and come back tomorrow, the list is still there with the ticks you already put on it. You don't re-plan. You resume.

**When to use it:** your task is too big for one sentence.
**When to skip it:** your task fits in one sentence.
